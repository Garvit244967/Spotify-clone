# Spotify Clone (Homepage with React)

## Files
- `index.html` — your original HTML, with only the homepage contents replaced by a React mount point and the Vite entry script added.
- `styles.css` — your original CSS, unchanged.
- `src/Home.jsx` — homepage component.
- `src/main.jsx` — mounts React inside `#home-content`.
- `package.json` — Vite + React setup.

## Run it
1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL Vite prints, usually `http://localhost:5173`.

Keep the folder structure as shown. Do not open `index.html` directly as a file; run it through Vite.
